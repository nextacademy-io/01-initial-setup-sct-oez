# Component

Component => ViewController, View (ReactElement) + Behaviour

Behaviour:

- View spezifisch

View:

- Behaviour spezifisch

Features:

- Zustand (State)
- Lebenszyklus (Lifecycle) (der vom Framework gemanaged wird)
  - Re-Rendering
    - Stateänderung
    - Kommunikation (mit anderen Komponenten)

React:

Eine Component ist zu verstehen als ein React.ReactElement als Funktion von State und Props
